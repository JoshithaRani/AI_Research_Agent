# 🧠 AI Research Agent

An **LLM-powered Agentic AI application** built using **Python, Gemini API, and Streamlit**.

The agent takes a user-defined goal and processes it through a multi-step workflow:

**Goal → Planning → Execution → Evaluation → Improvement → Final Result**

## 🛠️ Tech Stack

* Python
* Gemini API
* Google GenAI SDK
* Streamlit
* python-dotenv

## ✨ Features

* Goal-based task planning
* LLM-powered execution
* Automated evaluation
* Iterative result improvement
* Simple Streamlit interface
* Secure API key management

## 🎯 Purpose

Built as a hands-on project to apply concepts learned through **Agentic AI certification and learning**, and to explore how LLMs can be used in structured, goal-oriented workflows.
